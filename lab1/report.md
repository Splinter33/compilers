# Лабораторная работа 1. Задача А

Среда: WSL, Ubuntu, GCC 13.3.0, x86-64.
Цель: пройти этапы сборки программы от исходного кода до исполняемого файла.

## 1. Препроцессинг

```bash
g++ -E simple.cpp -o simple.i
wc -l simple.cpp simple.i
```

```text
   22 simple.cpp
 1073 simple.i
 1095 total
```

**1.** Исходный файл содержит 22 строки, результат препроцессинга - 1073 строки. В `simple.i` 588 непустых строк.

**2.** Перед `main` находятся глобальные переменные, функции программы, а выше - объявления из `<cstdio>` и вложенных заголовков, а также служебные маркеры строк. Размер увеличился, поскольку препроцессор раскрыл директиву `#include`.

**3.** Строка `"Result: %d, Counter: %d, Magic: %d\n"` осталась внутри вызова `printf` в `main`. Препроцессор не изменил ее содержимое.

## 2. Компиляция и оптимизации

```bash
g++ -S -masm=intel -O0 simple.cpp -o simple_O0.s
g++ -S -masm=intel -O2 simple.cpp -o simple_O2.s
wc -c simple_O0.s simple_O2.s
```

```text
2497 simple_O0.s
1692 simple_O2.s
4189 total
```

**4.** Размер ассемблерного текста уменьшился с 2497 до 1692 байт: примерно в 1,48 раза, или на 32,2%. Это сравнение текстовых файлов `.s`, а не размера машинного кода.

**5.** В файле без оптимизации функция `square` имеет метку `_Z6squarei` из-за кодирования имен C++. Умножение выполняет инструкция `imul eax, eax`.

**6.** Перед вызовом `sum_of_squares` в `main` выполняются:

```asm
mov esi, 4
mov edi, 3
call _Z14sum_of_squaresii
```

Первый аргумент передается через `edi`, второй - через `esi`, согласно соглашению о вызовах System V AMD64 для целочисленных аргументов.

**7.** При `-O2` отдельная функция `square` сохранилась, но ее вызовы в `sum_of_squares` заменены инструкциями умножения. В `main` результат `sum_of_squares(3, 4)` вычислен компилятором заранее и заменен числом 25. Отдельное определение `square` сохраняется как функция с внешним связыванием.

## 3. Объектный файл

```bash
g++ -c simple.cpp -o simple.o
nm -C simple.o
size simple.o
```

```text
0000000000000044 T bump_counter()
0000000000000013 T sum_of_squares(int, int)
0000000000000000 T square(int)
0000000000000000 r MAGIC
0000000000000000 B global_counter
000000000000005e T main
                 U printf

   text    data     bss     dec     hex filename
    400       0       4     404     194 simple.o
```

**8.** `MAGIC` имеет тип `r`: константа находится в секции данных только для чтения `.rodata`. Маленькая буква обозначает локальный символ: глобальная переменная `const` в данном C++-коде имеет внутреннее связывание. Тип `D` используется для инициализированных изменяемых данных.

**9.** `size` показывает суммарные размеры категорий секций в байтах:

- `text` занимает 400 байт и включает код и данные только для чтения;
- `data` - 0 байт;
- `bss` - 4 байта для обнуленного `global_counter`. 

Больше всего места занимает `text`, поскольку программа содержит несколько функций, строковый литерал и служебные данные. `dec` и `hex` показывают сумму 404 в десятичной и шестнадцатеричной форме; это не полный размер файла на диске.

## 4. Компоновка и запуск

```bash
g++ simple.o -o simple
./simple
```

**10.** Вывод программы:

```text
Result: 25, Counter: 1, Magic: 42
```

Результат равен 3 * 3 + 4 * 4 = 25, счетчик увеличен один раз, значение константы - 42.
